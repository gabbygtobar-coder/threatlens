# Fixtures

Placeholder directories for sample auth/access logs used from M1 onward (parser and detection work).

| Directory | Intended contents (later) |
| --- | --- |
| `normal/` | Benign login/access activity |
| `bruteforce/` | Failed-auth / brute-force style sequences |
| `mixed/` | Mixed benign and suspicious events |
| `edge/` | Odd or incomplete lines that a parser should handle |

These folders are empty in M0. Do not treat them as real telemetry.
